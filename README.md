# Smart Zone AI – Factory Digital Twin (proof of concept)

Open `index.html` in any modern browser. No install, build step, API keys or backend needed.

All observations are simulated, not real CCTV detections. Settings and alerts persist in LocalStorage; Reset restores defaults.

Limitations: single-file vanilla JavaScript (not React/Vite), no camera field-of-view cones, no dedicated Production Analytics charts, rule-based and trend-based monitoring only.
